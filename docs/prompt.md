### Prompt para el diseño del logo

Diseña un logo para una cafetería ficticia de programadores llamada The Coffee-Code Engine. El logo debe representar la unión entre el mundo del café y el desarrollo web.

Elementos principales:

Un grano de café como símbolo central.
Los signos de código < > rodeando o enmarcando el grano de café.
El diseño debe transmitir claramente la idea de café + programación.
Puede incluir una forma circular o tipo emblema, para que funcione bien como identidad visual del proyecto.

Estilo visual:

Minimalista, moderno y limpio.
Profesional pero cálido.
Fácil de reconocer y reproducir.
Con estética coherente con una cafetería de especialidad y con el entorno tecnológico.

Colores sugeridos:

Marrón oscuro, negro, beige, ocre o tonos café.
Puede incluir detalles en color claro para contraste.
Debe mantener una paleta sobria y armónica.

### Prompt para notas de cata de películas y discos:

Necesito redactar descripciones breves y creativas para una sección de películas y discos dentro de una ficha personal de una cafetería ficticia de programadores llamada The Coffee-Code Engine. Cada descripción debe funcionar como una ‘nota de cata’: tiene que relacionar la película o el disco con sensaciones del café, usando palabras como blend, latte, espresso, notas, cuerpo, aroma, retrogusto, tostado, dulzor, intensidad o final. El tono debe ser cálido, creativo y con humor sutil, manteniendo relación con la estética del proyecto, que mezcla cafetería de especialidad y desarrollo web. Las descripciones deben ser cortas, de una o dos oraciones, y adaptarse al estilo de cada película o disco.
